# عقل الـ NPCs (بديل الـ AI) — NPCBrain

مسجّل Autoload باسم `Dialogue` (نفس اسم وإشارات NPCDialogueBridge) فباقي اللعبة ماشي زي ما هو.
للرجوع للـ LLM: غيّر مسار `Dialogue` في project.godot لـ `res://scripts/NPCDialogueBridge.gd`.

## الملفات
| الملف | الدور |
|---|---|
| `NPCLexicon.gd` | بيانات فقط: كلمات، أصناف، مهن، أسماء، حكايات، جدول الذكاء من وثيقتك |
| `SpeechAnalyzer.gd` | تحليل كلام اللاعب: نية + نبرة + أصناف/أماكن/أرقام، يتحمل الأخطاء الإملائية |
| `NPCMind.gd` | شخصية ثابتة + ذكاء (رتبة/مهنة/عمر) + مزاج + ذاكرة لكل لاعب |
| `NPCGrammar.gd` | مولّد كلام تركيبي (مفيش جمل ثابتة) + منع التكرار + أسلوب (فصحى/عامية/عرق/عمر/مزاج) |
| `NPCBrain.gd` | المحرك: اختيار الفعل، مساومة، مهام مفاجئة، اتجاهات حسب موقعك، قرارات النشاط |

## بيتفاعل مع إيه
- **كلامك:** أدب/وقاحة/تهديد/إهانة، تحية، سؤال، تكرار نفس الرسالة، أخطاء إملائية، إنجليزي وعربي.
- **مكانك:** كشك/ساحة/غابة، الاتجاهات بتتحسب من موقعك واتجاه وشك (يمين/شمال/قدام).
- **الوقت والطقس:** ليل/صبح، مطر/عاصفة (`Dialogue.set_weather("rain")`).
- **حالتك:** HP، جوع، مستوى، فلوسك، عرقك.
- **ذاكرته:** بيفتكر مين كلمه، آخر موضوع، مودته ليك، الإهانات (محفوظ في `user://npc_memory.json`).

## إزاي تزوّد بدون كود
- كلمات جديدة: `data/npc_lexicon_extra.json`.
- جمل جديدة: زوّد قالب في `NPCGrammar.FRAGS`. الصيغة: `[أ|ب|ج]` اختيار عشوائي، `{slot}` قيمة من السياق.
- وحش قُتل أو حدث حصل: `Dialogue.add_world_fact("...")` والـ NPCs بتحكيه كإشاعة.
